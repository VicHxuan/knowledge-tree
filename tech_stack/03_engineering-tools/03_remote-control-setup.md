# 遥控器与接收机配置（QGC 校准）

配置接收机和遥控器，实现遥控器→接收机→(pixhawk上的PPM/SBUS RC接口)→pixhawk→(pixhawk上的FMU PWM OUT接口)→PWM分线板→电调→旋翼，即可实现遥控器手控起飞
具体的pixhawk内容单独整理

遥控器-接收器配置流程如下：

1.解锁遥控器，当前牌子为AT9S Pro
2.遥控器面板上方有黄色的“T”，如果未进行对频/接收器未接电，则T后面没有“信号格”
3.检查接收器端接线情况，PWM和SBUS是两种信号输出，对应2种颜色的灯和遥控器内的model设置，具体接线见说明
(长按遥控器model，在最后功能设置中，当前为将OUT选为PPM，这点待定)
4.为接收器供电(全机供电或电源→pixhawk→接收器供电)，接收器初始为
5.红色灯为PWM模式，蓝紫色灯为SBUS模式，双击小按钮进行切换模式
6.确认模式后，保持遥控器开机，长按按钮，灯闪烁，进行对频，灯长亮且遥控器T后有信号格，对频成功

遥控器配置：

首先：将pixhawk从机载电脑接口拔出连接到自己电脑，实现遥控器→接收机→pixhawk→自己电脑
这一点核心不在于自己电脑，而是要找一个有QGC的电脑，只是没必要在机载电脑装QGC

确认已正确连接/对频：QGC上方会显示，即使not ready，在遥控器上切换对应飞行模式(自稳，定点，定高，也会同步修改)
进入Vehicle Setup→Radio 点击 calibrate 开始校准，目前选择model2，按照右侧图像拨动摇杆，自动/手动next依次完成，拨动摇杆画面中会同步看到控制输出
