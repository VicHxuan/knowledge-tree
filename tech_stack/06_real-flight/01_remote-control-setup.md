# 遥控器与接收机配置

## 1. 概述

遥控链路将操作者输入传给飞控，飞控根据模式和控制配置产生执行器输出。配置顺序为接收机连接、对频、通道校准、模式映射和失联行为验证。

## 2. 基础与定义

### 2.1 信号链

遥控器通过无线链路连接接收机，接收机经飞控支持的 RC 接口发送通道数据。SBUS、PPM 和独立 PWM 的协议、接线与配置不同，按接收机和飞控板的型号手册确认。飞控到电调的输出协议另行配置。

### 2.2 通道语义

记录横滚、俯仰、油门、偏航以及模式开关的通道号、方向和范围。摇杆布局按操作者实际设置选择，校准结果应与屏幕显示的动作一致。

## 3. 核心原理

### 3.1 对频与校准

对频建立遥控器和接收机的无线关联，校准确定各通道的最小值、中值、最大值和方向。QGroundControl 根据收到的通道变化完成映射。[QGC Radio Setup](https://docs.qgroundcontrol.com/master/en/qgc-user-guide/setup_view/radio.html)

### 3.2 模式与失联

开关位置映射到所需模式，并在飞控状态中验证。失联时的接收机输出和飞控处理共同决定后续行为；配置后在拆桨条件下验证信号丢失、恢复及模式状态。

## 4. 实现与应用

### 4.1 配置流程

1. 拆除螺旋桨，核对接收机供电、电压与信号引脚。
2. 按具体型号完成协议选择和对频，检查链路状态。
3. 连接运行 QGroundControl 的电脑，观察通道是否随摇杆变化。
4. 在 Radio 页面按提示完成范围、中位和方向校准。
5. 配置模式开关，检查每个位置对应的飞控状态。
6. 保存参数和设备型号，验证失联处理。

## 5. 分析与总结

对频成功、通道校准和飞控可飞状态分别验收。遥控配置完成后，继续核对传感器、执行器、模式和定位条件，再进入对应的飞行验证流程。
