# 无人机导航场景设计

## 1. 概述

导航场景定义无人机从何处出发、前往何处以及途中遇到哪些障碍。训练场景提供学习分布，验证场景用于选择模型，测试场景用于报告最终结果。场景生成器与划分清单共同决定实验是否可重复。

## 2. 基础与定义

### 2.1 场景参数

用 $\xi$ 表示地图几何、起终点、动态目标轨迹、传感器条件与随机种子，训练任务从 $p_{\mathrm{train}}(\xi)$ 采样。保存生成器版本与参数，随机种子只有在相同生成逻辑下才定义相同场景。

### 2.2 难度维度

| 维度 | 可记录参数 |
|---|---|
| 静态几何 | 障碍密度、最小通道宽度、遮挡与高度范围 |
| 导航目标 | 起终距离、高度差、必要转弯与可达性 |
| 动态交互 | 障碍速度、数量、交叉角、接近时刻 |
| 观测条件 | 视场、量程、噪声、丢帧与延迟 |
| 多机任务 | 组规模、相对目标、共享空间与交互规则 |

## 3. 核心原理

### 3.1 静态场景

先按机体包络膨胀障碍，检查起点和目标的有效性，再定义任务是否要求存在可行通路。训练可达导航时，保留可达性检查结果；包含封闭环境的实验则单独报告不可达任务比例和停止行为。

### 3.2 动态场景

迎面、交叉、追越和遮挡后出现分别覆盖不同相对运动。将障碍轨迹或随机流绑定到场景标识，确保比较方法面对相同外部条件。障碍会对无人机作出响应时，固定其响应模型并报告交互性质。

### 3.3 数据划分与课程

按地图族、几何实例和轨迹模板划分训练、验证和测试，避免只更换随机种子却保留高度相似布局。课程从较宽通道、较慢障碍或较短目标距离开始，逐步调整难度。固定测试分布独立于课程推进。

## 4. 实现与应用

### 4.1 场景验收

检查初始碰撞、终点占据、障碍越界、无效深度和环境间串扰。为典型场景保存可视化和确定性重放记录。批量环境的物理隔离与任务内多机交互分别建模。

### 4.2 实验矩阵

先固定其他条件，逐一改变静态密度、动态速度、组规模和感知误差，再选择关键因素做组合实验。每个单元记录尝试回合数、有效回合数和排除原因，避免失败任务在汇总前消失。

## 5. 分析与总结

场景难度由几何、运动和观测共同决定。地图更密并不必然使所有起终点更难，报告时需同时描述通道、目标和动态相遇条件。训练分布与测试分布的区别应能从清单复核。
