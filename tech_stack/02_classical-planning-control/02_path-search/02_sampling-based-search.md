# 采样规划与路线图

## 1. 概述

采样规划通过有限状态样本近似连续自由空间。RRT 增长搜索树，RRT* 进一步优化父节点与连接，PRM 构建可重复查询的路线图。

## 2. 基础与定义

### 2.1 规划接口

定义状态空间、自由空间、距离度量、局部连接器和边碰撞检查。一次有效扩展要求连接过程中所有状态满足模型约束。

### 2.2 代价与解

路径代价可以是长度、时间或控制消耗。几何距离用于搜索邻域时，应与局部连接能力相匹配。

## 3. 核心原理

### 3.1 RRT 扩展

采样 $x_{\rm rand}$，选择最近树节点 $x_{\rm near}$，通过局部连接器产生 $x_{\rm new}$。新边通过验证后加入树；目标连接也需要完整边检查。

### 3.2 RRT* 的局部优化

在邻域中选择最小累计代价父节点，再尝试通过新节点改善邻居：

$$
\operatorname{parent}(x)=\arg\min_{v\in\operatorname{Near}(x)}[g(v)+c(v,x)].
$$

重新连接后，将代价变化传播到全部后代。经典几何问题使用随样本数变化的邻域半径 $r_n=\min\{\eta,\gamma(\log n/n)^{1/d}\}$，其常数和可达性条件参与渐近最优性保证。

<details class="kt-derivation" id="rrt-rewiring">
<summary>重连的数据依赖</summary>

```text
对新状态选择可连接且累计代价最小的父节点
插入新状态并记录其子节点集合
对附近节点检查经新状态的候选代价
若更优且连接有效：替换父边，并向整棵子树传播代价变化
更新目标候选及当前最佳完整路径
```

碰撞检查作用于边，代价传播作用于树的全部依赖节点。

</details>

### 3.3 PRM 与多次查询

PRM 在自由空间中采样并连接近邻形成图。查询时接入起终点，再执行图搜索。PRM* 按满足理论条件的邻域规则扩展连接，以获得相应渐近最优性质。

## 4. 实现与应用

### 4.1 评估流程

在相同碰撞模型和预算下比较成功率、首次解时间、最佳代价随时间变化及碰撞检查次数。固定随机种子用于复现，并用多个种子评价采样波动。

## 5. 分析与总结

概率完备性描述在适当可行性、采样和局部连接条件下，失败概率随样本数增加而趋零。渐近最优性描述极限代价；有限预算下仍需直接评价解的质量。
