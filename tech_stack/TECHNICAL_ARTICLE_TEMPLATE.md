# 技术文章写作规范与模板

本规范用于 `tech_stack/` 六大领域下的全部技术文章，包含已发布文章和草稿。规范本身不注册为教程。以 [PPO](03_learning-based-planning/02_rl-algorithms/02_model-free-rl/04_ppo.md) 为主线与折叠细节的示范。

## 写作目标

读者应先理解问题、输入输出和完整流程，再按需要展开证明与代码。文章只讨论一个明确主题；复合主题保留有层次的子章节。定义先于使用，符号、下标、坐标系和单位保持一致。

每篇文章只有一个 H1，与 `content-map.json` 的 title 一致。六个 H2 固定，H3/H4 按内容展开。推荐按所属模块编号（如 3.1、3.2、4.1），同一篇文章不混用旧的全局编号。已有标题变更时保留被引用的锚点或同步修复链接。

标题采用标准、具体的学术名词短语，如“网络结构”“优势估计”“参数更新”“实验设置”。避免口语问句、操作句和抽象口号；同一概念下的细节用正文或列表组织，不为每一步操作单设小标题。标题不附重复英文译名或无信息的括注，首次术语定义放在正文；保留数学表达式、单位、版本和必要的消歧信息。折叠标题遵循同一要求。

## 主线与展开材料

| 默认可见的主线 | 默认收起的细节 |
|---|---|
| 问题、关键定义、输入输出和适用条件 | 逐步代数、长证明和历史背景 |
| 核心公式及其含义 | 公式完整推导与补充性质 |
| 算法闭环、数据流、短伪代码 | 完整数值算例、实现变体、长代码 |
| 正确使用方法必需的边界条件 | 专项排错、扩展阅读 |

每个展开块前给出结论或说明它回答的问题。主线目录用 H2/H3；推导内部优先使用段落和步骤，确有必要时用 H4。允许多个块同时展开，不把整个核心原理模块放进折叠层。

使用原生 HTML，summary 后及结束标签前留空行，正文不要整体缩进：

```html
<details class="kt-derivation" id="topic-proof-name">
<summary>定理证明</summary>

在此写 Markdown、公式、表格或代码。

</details>
```

ID 使用稳定英文短语，在同页内唯一。锚点可直接引用 `#topic-proof-name`。全站组件负责批量展开、链接定位和打印；正文不写交互脚本。

## 可复制骨架

```markdown
# 文章标题

## 1. 概述

说明问题、方法定位、适用场景，以及读完能够解释或完成什么。

## 2. 基础与定义

### 2.1 基本概念

说明所需概念、输入输出、数据维度或工具环境。

### 2.2 符号与假设

统一符号、坐标系、下标、版本和必要假设。

## 3. 核心原理

### 3.1 理论模型

按因果关系说明核心机制，先给结论与关键公式，再就近提供折叠推导。

### 3.2 算法流程

给出数据流、算法步骤或短伪代码，标清各阶段如何连接。

## 4. 实现与应用

### 4.1 算法实现

将公式与代码、数据结构或命令对应起来。长代码可折叠或链接仓库中的可运行示例。

### 4.2 实验与验证

给出输入、结果和可复核的检查方法。

## 5. 分析与总结

### 5.1 方法分析

交代方法边界、误差来源、实现差异和排错顺序。

### 5.2 总结

提炼主线中读者应掌握的结论，不添加未经论证的新观点。

## 6. 关联与参考

### 6.1 相关工作

说明前置、相关、后续与工程实践；链接只能指向线上可访问的页面。

### 6.2 参考文献

列出支持正文的一手论文、官方文档、开源实现及版本或提交。
```

## 不同主题如何使用同一骨架

| 模块 | 理论与算法 | 工程工具与流程 |
|---|---|---|
| 概述 | 问题、动机、定位 | 工具用途、任务目标 |
| 基础与定义 | 符号、模型、假设 | 环境、版本、输入输出 |
| 核心原理 | 机制、公式、算法闭环 | 工作机制、系统关系、操作原理 |
| 实现与应用 | 伪代码、数值例子、实验 | 命令、配置、预期现象、复现 |
| 分析与总结 | 边界、复杂度、误区 | 排错、限制、经验的适用范围 |
| 关联与参考 | 相关算法、论文、代码 | 相关工具、官方文档、源码 |

## 整理旧文与草稿

保留有价值的公式、代码、图表、引用和实验条件；结构重排与技术纠错分别说明。确实错误的内容应依据来源修正，不以“保留原文”为由继续传播。粘贴材料先去重，恢复代码和公式格式，再核实内容。

没有足够依据的模块写 `> 待补充。`；草稿也保留六模块。发布状态由映射控制，不能因为补了标题就视为内容完成。通用推导先保留在可阅读页面内，迁往基础文章时先完成并发布目标页，再替换为引用。

数学使用 `$...$` / `$$...$$`，代码块注明语言。示例程序在 `examples/` 单处维护；构建下载由同步脚本的显式清单生成。原件之间优先使用相对 `.md` 链接，或稳定网站 URL；不要链接本地论文路径或不可发布的私有资料。

## 完成标准

六模块齐全；主线在关闭细节时仍连贯；公式与代码可复核；网页的目录、锚点、搜索、折叠、打印正常。按 [贡献指南](../CONTRIBUTING.md) 完成对应校验并清理临时产物。
