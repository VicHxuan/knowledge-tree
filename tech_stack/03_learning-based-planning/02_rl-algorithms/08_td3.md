# TD3 算法完整解析与代码实现

## 1. 概述（Overview）

TD3 是对 DDPG 算法的重大改进。在连续控制任务中，基于价值的强化学习方法容易受到函数近似误差的影响，从而导致 Q 值的高估偏差和误差的不断累积。TD3 通过截断的双 Q 学习、目标策略平滑正则化以及延迟策略更新这三项核心技术，有效解决了这些问题。

## 3. 核心原理（Core Principles）

### 1. 完整的数学公式与算法流程

TD3 的完整算法流程严格遵循以下数学步骤，涵盖了从初始化到网络更新的全生命周期。

#### 步骤 1：初始化网络与经验池

1. 定义并初始化策略网络（Actor）参数 $\phi$，以及两个价值网络（Critic）参数 $\theta_1, \theta_2$。
2. 初始化对应的目标网络，参数分别为 $\phi', \theta'_1, \theta'_2$，初始时将其权重直接复制于对应的原网络：
   $\phi' \leftarrow \phi$
   $\theta'_1 \leftarrow \theta_1$
   $\theta'_2 \leftarrow \theta_2$
3. 初始化经验回放池 $\mathcal{B}$。

#### 步骤 2：动作选择与数据收集

在每个时间步中，智能体观察当前状态 $s$，通过 Actor 网络输出确定性动作，并加入探索噪声以增加对环境的探索。动作需截断以保证在环境允许的合法范围内：
$a = \text{clip}(\pi_\phi(s) + \epsilon, a_{low}, a_{high})$
其中探索噪声服从正态分布 $\epsilon \sim \mathcal{N}(0, \sigma_{expl})$。
执行动作 $a$ 后，环境返回奖励 $r$、是否结束的标志 $d$ 以及下一个状态 $s'$。将状态转移元组 $(s, a, r, s', d)$ 存入回放池 $\mathcal{B}$。

#### 步骤 3：目标 Q 值计算（包含平滑与截断）

当回放池的数据量满足要求后，每次训练从 $\mathcal{B}$ 中随机采样包含 $N$ 个转移元组的批次。
首先，为目标策略网络输出的动作加入**截断的平滑噪声**。这使得策略在更新时更加平滑，避免 Critic 网络对狭窄的 Q 值峰值产生过拟合：
$\tilde{a} = \text{clip}(\pi_{\phi'}(s') + \epsilon, a_{low}, a_{high})$
其中添加的噪声被限制在一定范围内 $\epsilon \sim \text{clip}(\mathcal{N}(0, \sigma), -c, c)$。

接着，使用**截断的双 Q 学习**计算目标 Q 值。将下一个状态 $s'$ 和平滑后的目标动作 $\tilde{a}$ 输入两个目标 Critic 网络，取二者的最小值以消除高估偏差：
$y = r + (1 - d) \gamma \min_{i=1,2} Q_{\theta'_i}(s', \tilde{a})$

#### 步骤 4：Critic 网络更新

计算当前两个 Critic 网络对当前状态和动作的 Q 值估计 $Q_{\theta_1}(s, a)$ 和 $Q_{\theta_2}(s, a)$。
通过最小化均方误差同时更新两个 Critic 网络的参数 $\theta_1$ 和 $\theta_2$：
$L(\theta_i) = \frac{1}{N} \sum (y - Q_{\theta_i}(s, a))^2 \quad \text{for } i=1,2$

#### 步骤 5：Actor 网络延迟更新

如果强行在 Critic 误差较高时更新 Actor，会导致策略发散。因此 TD3 采用**延迟更新**，每隔固定的步数（通常设定为 2 步）才更新一次 Actor 网络。
Actor 的目标是最大化 Q 值，更新时仅依赖第一个 Critic 网络 $Q_{\theta_1}$ 提供梯度指导。通过确定性策略梯度定理计算参数 $\phi$ 的梯度：
$\nabla_\phi J(\phi) = \frac{1}{N} \sum \nabla_a Q_{\theta_1}(s, a)|*{a=\pi*\phi(s)} \nabla_\phi \pi_\phi(s)$
使用梯度上升法更新 Actor 参数 $\phi$。

#### 步骤 6：目标网络软更新

在更新完 Actor 网络的同一拍，对所有的目标网络进行参数平滑软更新，$\tau$ 是一个极小的值（如 0.005）：
$\theta'_i \leftarrow \tau \theta_i + (1 - \tau) \theta'_i \quad \text{for } i=1,2$
$\phi' \leftarrow \tau \phi + (1 - \tau) \phi'$

## 4. 实现与应用（Implementation & Applications）

### 2. 核心代码架构实现

以下代码基于 CleanRL 进行了提取与重构，去除了日志、参数解析、环境向量化等辅助性工作，高度抽象了状态和动作维度的处理，完整保留了上述数学流程中的核心算法逻辑，完全符合 Python 与 PyTorch 规范。

```python
import numpy as np
import torch
import torch.nn as nn
import torch.nn.functional as F
import torch.optim as optim

# =======================================
# 1. 网络架构定义
# =======================================

class QNetwork(nn.Module):
    """Critic 网络：输入状态和动作，输出对应的 Q 值"""
    def __init__(self, obs_dim, action_dim):
        super().__init__()
        self.fc1 = nn.Linear(obs_dim + action_dim, 256)
        self.fc2 = nn.Linear(256, 256)
        self.fc3 = nn.Linear(256, 1)

    def forward(self, x, a):
        x = torch.cat([x, a], dim=1)
        x = F.relu(self.fc1(x))
        x = F.relu(self.fc2(x))
        x = self.fc3(x)
        return x

class Actor(nn.Module):
    """Actor 网络：输入状态，输出确定性动作"""
    def __init__(self, obs_dim, action_dim, action_low, action_high):
        super().__init__()
        self.fc1 = nn.Linear(obs_dim, 256)
        self.fc2 = nn.Linear(256, 256)
        self.fc_mu = nn.Linear(256, action_dim)
        
        self.register_buffer("action_scale", torch.tensor((action_high - action_low) / 2.0, dtype=torch.float32))
        self.register_buffer("action_bias", torch.tensor((action_high + action_low) / 2.0, dtype=torch.float32))

    def forward(self, x):
        x = F.relu(self.fc1(x))
        x = F.relu(self.fc2(x))
        x = torch.tanh(self.fc_mu(x))
        return x * self.action_scale + self.action_bias

# =======================================
# 2. 核心算法类与训练逻辑
# =======================================

class TD3Agent:
    def __init__(self, obs_dim, action_dim, action_low, action_high, device):
        self.device = device
        self.action_low = torch.tensor(action_low).to(device)
        self.action_high = torch.tensor(action_high).to(device)
        
        self.actor = Actor(obs_dim, action_dim, action_low, action_high).to(device)
        self.qf1 = QNetwork(obs_dim, action_dim).to(device)
        self.qf2 = QNetwork(obs_dim, action_dim).to(device)
        
        self.target_actor = Actor(obs_dim, action_dim, action_low, action_high).to(device)
        self.qf1_target = QNetwork(obs_dim, action_dim).to(device)
        self.qf2_target = QNetwork(obs_dim, action_dim).to(device)
        
        self.target_actor.load_state_dict(self.actor.state_dict())
        self.qf1_target.load_state_dict(self.qf1.state_dict())
        self.qf2_target.load_state_dict(self.qf2.state_dict())
        
        self.q_optimizer = optim.Adam(list(self.qf1.parameters()) + list(self.qf2.parameters()), lr=3e-4)
        self.actor_optimizer = optim.Adam(list(self.actor.parameters()), lr=3e-4)
        
        self.gamma = 0.99
        self.tau = 0.005
        self.policy_noise = 0.2
        self.noise_clip = 0.5
        self.policy_frequency = 2

    def get_action(self, obs, exploration_noise=0.1):
        """步骤2：环境交互与动作选择"""
        with torch.no_grad():
            obs_tensor = torch.Tensor(obs).unsqueeze(0).to(self.device)
            action = self.actor(obs_tensor)
            noise = torch.normal(0, self.actor.action_scale * exploration_noise)
            action += noise
            action = torch.clamp(action, self.action_low, self.action_high)
        return action.cpu().numpy()[0]

    def train_step(self, replay_buffer, batch_size, global_step):
        """执行一个批次的完整训练更新"""
        observations, actions, rewards, next_observations, dones = replay_buffer.sample(batch_size)
        
        # 步骤3：计算目标 Q 值
        with torch.no_grad():
            noise = (torch.randn_like(actions) * self.policy_noise).clamp(-self.noise_clip, self.noise_clip)
            noise = noise * self.target_actor.action_scale
            
            next_state_actions = self.target_actor(next_observations) + noise
            next_state_actions = torch.clamp(next_state_actions, self.action_low, self.action_high)
            
            qf1_next_target = self.qf1_target(next_observations, next_state_actions)
            qf2_next_target = self.qf2_target(next_observations, next_state_actions)
            min_qf_next_target = torch.min(qf1_next_target, qf2_next_target)
            
            next_q_value = rewards + (1 - dones) * self.gamma * min_qf_next_target

        # 步骤4：计算并反向传播 Critic 的损失
        qf1_a_values = self.qf1(observations, actions)
        qf2_a_values = self.qf2(observations, actions)
        qf1_loss = F.mse_loss(qf1_a_values, next_q_value)
        qf2_loss = F.mse_loss(qf2_a_values, next_q_value)
        qf_loss = qf1_loss + qf2_loss

        self.q_optimizer.zero_grad()
        qf_loss.backward()
        self.q_optimizer.step()

        # 步骤5：延迟更新 Actor 网络
        if global_step % self.policy_frequency == 0:
            actor_loss = -self.qf1(observations, self.actor(observations)).mean()
            
            self.actor_optimizer.zero_grad()
            actor_loss.backward()
            self.actor_optimizer.step()

            # 步骤6：目标网络软更新
            self._soft_update(self.actor, self.target_actor)
            self._soft_update(self.qf1, self.qf1_target)
            self._soft_update(self.qf2, self.qf2_target)

    def _soft_update(self, network, target_network):
        for param, target_param in zip(network.parameters(), target_network.parameters()):
            target_param.data.copy_(self.tau * param.data + (1 - self.tau) * target_param.data)


# =======================================
# 3. 主循环抽象调用演示
# =======================================
def main_training_loop(env, agent, replay_buffer, max_steps, batch_size, learning_starts):
    obs = env.reset()
    for global_step in range(max_steps):
        
        if global_step < learning_starts:
            action = env.action_space.sample()
        else:
            action = agent.get_action(obs)
            
        next_obs, reward, done, info = env.step(action)
        replay_buffer.add(obs, action, reward, next_obs, done)
        obs = next_obs
        
        if done:
            obs = env.reset()

        if global_step > learning_starts:
            agent.train_step(replay_buffer, batch_size, global_step)
```
