# TD3 算法完整解析与代码实现

## 1. 概述

TD3 在 DDPG 的确定性 Actor-Critic 架构上引入双 Q 目标、目标策略平滑和延迟策略更新。这三项机制分别作用于价值目标、目标动作与更新频率，减轻价值估计误差对策略学习的影响。

## 2. 基础与定义

### 2.1 网络结构

| 网络 | 输出 | 更新方式 |
| --- | --- | --- |
| Actor $\mu_\theta(s)$ | 确定性动作 | 最大化第一个 Critic 的动作价值 |
| 两个 Critic $Q_{\phi_1},Q_{\phi_2}$ | 同一奖励下的动作价值 | 分别拟合同一 TD 目标 |
| 目标 Actor $\mu_{\bar\theta}$ | 下一状态的目标动作 | 参数滑动平均 |
| 两个目标 Critic $Q_{\bar\phi_1},Q_{\bar\phi_2}$ | 下一状态动作价值 | 参数滑动平均 |

### 2.2 训练数据

从经验池 $\mathcal B$ 采样转移 $(s,a,r,s',d)$，其中 $r$ 是执行 $a$ 后获得的奖励，$d$ 表示真正终止。外部时间截断时 $d=0$，$s'$ 使用重置前末状态。TD3 复用不同历史策略产生的数据，属于离策略方法。

## 3. 核心原理

### 3.1 损失与梯度

两个 Critic 独立最小化平方 TD 误差，Actor 最大化第一个 Critic 对当前动作的评价：

$$
L_{Q_i}(\phi_i)=\mathbb E_{\mathcal B}[(Q_{\phi_i}(s,a)-y)^2],\qquad
L_\pi(\theta)=-\mathbb E_{s\sim\mathcal B}[Q_{\phi_1}(s,\mu_\theta(s))].
$$

将目标 $y$ 固定，Critic 梯度为

$$
\nabla_{\phi_i}L_{Q_i}=2\mathbb E_{\mathcal B}[(Q_{\phi_i}-y)\nabla_{\phi_i}Q_{\phi_i}].
$$

更新 Actor 时固定 Critic 参数，保留动作对 Actor 的导数：

$$
\nabla_\theta L_\pi
=-\mathbb E_{s\sim\mathcal B}\!\left[(\nabla_\theta\mu_\theta(s))^\top
\nabla_aQ_{\phi_1}(s,a)\big|_{a=\mu_\theta(s)}\right].
$$

双 Critic 的最小值进入训练目标 $y$，Actor 的直接梯度来自 $Q_{\phi_1}$。

### 3.2 双 Q 目标

给定下一状态的平滑目标动作 $\tilde a'$，两个目标 Critic 的较小值构成自举目标：

$$
y=r+\gamma(1-d)\min_{i=1,2}Q_{\bar\phi_i}(s',\tilde a').
$$

Actor 的最大化倾向会利用 Q 估计中的正误差。取较小值使备份更保守，降低这类误差持续进入后续目标的程度。

<details class="kt-derivation" id="td3-estimation-bias">
<summary>双 Q 估计误差</summary>

固定状态动作，设两个估计为 $Q_i=Q^*+e_i$。利用恒等式

$$
\min(e_1,e_2)=\frac{e_1+e_2-|e_1-e_2|}{2},
$$

若 $\mathbb E[e_1]=\mathbb E[e_2]=0$，则

$$
\mathbb E[\min(Q_1,Q_2)]-Q^*
=-\frac12\mathbb E[|e_1-e_2|]\le0.
$$

该结果说明最小值带来向下偏差。若两个误差完全相同，最小值保留共同误差；实际学习中的偏差还取决于误差均值、相关性以及目标随训练的变化。

</details>

### 3.3 目标策略平滑

在目标 Actor 动作附近加入截断噪声，再限制到动作范围：

$$
\epsilon=\operatorname{clip}(\xi,-c,c),\quad \xi\sim\mathcal N(0,\sigma^2I),
\qquad
\tilde a'=\operatorname{clip}(\mu_{\bar\theta}(s')+\epsilon,a_{\min},a_{\max}).
$$

目标由邻域内动作的价值采样构成，使 Critic 对狭窄动作峰值的依赖减弱。探索噪声用于环境采样，平滑噪声用于构造训练目标，二者承担不同的数据处理任务。

### 3.4 延迟更新与目标网络

每进行 $k$ 次 Critic 更新，执行一次 Actor 更新，并同步滑动更新三个目标网络：

$$
\bar\theta\leftarrow\tau\theta+(1-\tau)\bar\theta,
\qquad
\bar\phi_i\leftarrow\tau\phi_i+(1-\tau)\bar\phi_i.
$$

延迟为价值拟合提供更多更新，滑动平均降低自举目标的变化速度。$k$ 按 Critic 梯度更新次数计数。

## 4. 实现与应用

### 4.1 训练流程

1. 用带探索噪声的 Actor 采集转移并存入经验池。
2. 采样小批量转移，以平滑目标动作和目标双 Q 最小值构造 $y$。
3. 固定 $y$，更新两个 Critic。
4. 到达延迟更新间隔时，更新 Actor 和三个目标网络。
5. 继续环境采样与经验回放。

### 4.2 实现示例

<details class="kt-derivation" id="td3-pytorch-update">
<summary>TD3 的 PyTorch 实现</summary>

经验池由调用方提供。`sample` 返回同设备浮点张量：状态 `[B, obs_dim]`、动作 `[B, action_dim]`、奖励和终止标志 `[B, 1]`；`dones` 存真正终止标志。动作上下界为有限的一维 NumPy 数组。

代码将平滑噪声参数解释为归一化动作尺度，再乘 `action_scale` 转到环境动作单位。主循环使用 Gymnasium 单环境接口，环境由循环显式重置；外部截断保留重置前的下一状态。

```python
import numpy as np
import torch
import torch.nn as nn
import torch.nn.functional as F
import torch.optim as optim

# =======================================
# 1. 网络架构定义
# =======================================

class QNetwork(nn.Module):
    """Critic 网络：输入状态和动作，输出对应的 Q 值"""
    def __init__(self, obs_dim, action_dim):
        super().__init__()
        self.fc1 = nn.Linear(obs_dim + action_dim, 256)
        self.fc2 = nn.Linear(256, 256)
        self.fc3 = nn.Linear(256, 1)

    def forward(self, x, a):
        x = torch.cat([x, a], dim=1)
        x = F.relu(self.fc1(x))
        x = F.relu(self.fc2(x))
        x = self.fc3(x)
        return x

class Actor(nn.Module):
    """Actor 网络：输入状态，输出确定性动作"""
    def __init__(self, obs_dim, action_dim, action_low, action_high):
        super().__init__()
        self.fc1 = nn.Linear(obs_dim, 256)
        self.fc2 = nn.Linear(256, 256)
        self.fc_mu = nn.Linear(256, action_dim)

        self.register_buffer("action_scale", torch.tensor((action_high - action_low) / 2.0, dtype=torch.float32))
        self.register_buffer("action_bias", torch.tensor((action_high + action_low) / 2.0, dtype=torch.float32))

    def forward(self, x):
        x = F.relu(self.fc1(x))
        x = F.relu(self.fc2(x))
        x = torch.tanh(self.fc_mu(x))
        return x * self.action_scale + self.action_bias

# =======================================
# 2. 核心算法类与训练逻辑
# =======================================

class TD3Agent:
    def __init__(self, obs_dim, action_dim, action_low, action_high, device):
        self.device = device
        self.action_low = torch.as_tensor(action_low, dtype=torch.float32, device=device)
        self.action_high = torch.as_tensor(action_high, dtype=torch.float32, device=device)

        self.actor = Actor(obs_dim, action_dim, action_low, action_high).to(device)
        self.qf1 = QNetwork(obs_dim, action_dim).to(device)
        self.qf2 = QNetwork(obs_dim, action_dim).to(device)

        self.target_actor = Actor(obs_dim, action_dim, action_low, action_high).to(device)
        self.qf1_target = QNetwork(obs_dim, action_dim).to(device)
        self.qf2_target = QNetwork(obs_dim, action_dim).to(device)

        self.target_actor.load_state_dict(self.actor.state_dict())
        self.qf1_target.load_state_dict(self.qf1.state_dict())
        self.qf2_target.load_state_dict(self.qf2.state_dict())

        self.q_optimizer = optim.Adam(list(self.qf1.parameters()) + list(self.qf2.parameters()), lr=3e-4)
        self.actor_optimizer = optim.Adam(list(self.actor.parameters()), lr=3e-4)

        self.gamma = 0.99
        self.tau = 0.005
        self.policy_noise = 0.2
        self.noise_clip = 0.5
        self.policy_frequency = 2

    def get_action(self, obs, exploration_noise=0.1):
        """步骤2：环境交互与动作选择"""
        with torch.no_grad():
            obs_tensor = torch.Tensor(obs).unsqueeze(0).to(self.device)
            action = self.actor(obs_tensor)
            noise = torch.normal(0, self.actor.action_scale * exploration_noise)
            action += noise
            action = torch.clamp(action, self.action_low, self.action_high)
        return action.cpu().numpy()[0]

    def train_step(self, replay_buffer, batch_size, update_step):
        """执行一个批次的完整训练更新"""
        observations, actions, rewards, next_observations, dones = replay_buffer.sample(batch_size)

        # 步骤3：计算目标 Q 值
        with torch.no_grad():
            noise = (torch.randn_like(actions) * self.policy_noise).clamp(-self.noise_clip, self.noise_clip)
            noise = noise * self.target_actor.action_scale

            next_state_actions = self.target_actor(next_observations) + noise
            next_state_actions = torch.clamp(next_state_actions, self.action_low, self.action_high)

            qf1_next_target = self.qf1_target(next_observations, next_state_actions)
            qf2_next_target = self.qf2_target(next_observations, next_state_actions)
            min_qf_next_target = torch.min(qf1_next_target, qf2_next_target)

            next_q_value = rewards + (1 - dones) * self.gamma * min_qf_next_target

        # 步骤4：计算并反向传播 Critic 的损失
        qf1_a_values = self.qf1(observations, actions)
        qf2_a_values = self.qf2(observations, actions)
        qf1_loss = F.mse_loss(qf1_a_values, next_q_value)
        qf2_loss = F.mse_loss(qf2_a_values, next_q_value)
        qf_loss = qf1_loss + qf2_loss

        self.q_optimizer.zero_grad()
        qf_loss.backward()
        self.q_optimizer.step()

        # 步骤5：延迟更新 Actor 网络
        if update_step % self.policy_frequency == 0:
            self.qf1.requires_grad_(False)
            actor_loss = -self.qf1(observations, self.actor(observations)).mean()

            self.actor_optimizer.zero_grad()
            actor_loss.backward()
            self.actor_optimizer.step()
            self.qf1.requires_grad_(True)

            # 步骤6：目标网络软更新
            self._soft_update(self.actor, self.target_actor)
            self._soft_update(self.qf1, self.qf1_target)
            self._soft_update(self.qf2, self.qf2_target)

    @torch.no_grad()
    def _soft_update(self, network, target_network):
        for param, target_param in zip(network.parameters(), target_network.parameters()):
            target_param.lerp_(param, self.tau)


# =======================================
# 3. 主循环抽象调用演示
# =======================================
def main_training_loop(env, agent, replay_buffer, max_steps, batch_size, learning_starts):
    obs, _ = env.reset()
    update_step = 0
    for global_step in range(max_steps):

        if global_step < learning_starts:
            action = env.action_space.sample()
        else:
            action = agent.get_action(obs)

        next_obs, reward, terminated, truncated, _ = env.step(action)
        replay_buffer.add(obs, action, reward, next_obs, terminated)
        obs = next_obs

        if terminated or truncated:
            obs, _ = env.reset()

        if global_step > learning_starts:
            update_step += 1
            agent.train_step(replay_buffer, batch_size, update_step)
```

## 5. 分析与总结

### 5.1 机制比较

| 机制 | 直接改变的量 | 对梯度的影响 |
| --- | --- | --- |
| 双 Q 最小值 | 自举目标 $y$ | 改变两个 Critic 的 TD 残差 |
| 目标策略平滑 | 目标动作 $\tilde a'$ | 改变 Critic 拟合的局部价值目标 |
| 延迟策略更新 | Actor 更新频率 | 降低策略对暂态价值误差的响应频率 |
| 目标网络平均 | 自举网络参数 | 减缓未来批次目标的变化 |

两个 Critic 估计同一回报；独立初始化与训练产生不同误差，最小值聚合用于抑制高估。基于奖励分解的多个 Critic 则分别估计不同回报，详见[多价值网络与价值估计](../01_rl-foundations/05_multi-critic.md)。

### 5.2 核心结论

TD3 保留确定性策略梯度，以保守和平滑的价值目标训练 Critic，再以较低频率更新 Actor。其效果取决于 Critic 误差、动作邻域尺度与更新节奏的共同作用。
