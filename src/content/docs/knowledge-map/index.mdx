以交互式图谱呈现全部知识点的**前置知识**（实线箭头）与**相关主题**（虚线）关系：

- **依赖视图**：按前置关系分层，左侧是根节点，向右逐层展开；
- **领域视图**：按六大知识领域分列查看；
- **筛选**：按状态（已发布 / 撰写中）与领域过滤，支持按标题搜索（不匹配的节点会变淡）；
- **聚焦**：选中节点后，它与其直接前置、后续依赖、相关主题保持常亮，其余节点与边淡出，便于看清局部结构；详情面板中可查看「谁依赖它」；
- **详情与直达**：单击节点查看描述、前置、后续依赖与相关主题；双击已发布节点直接跳转对应页面；
- **URL 状态**：视图与选中节点会写入地址栏（如 `?view=dependency&node=<知识点>`），文章页的「在图谱中查看」链接即依赖此机制直达定位。

进度图较大，可以拖拽平移、滚轮缩放（触屏支持双指缩放）；右下角有缩放控件，右侧小地图可用于快速定位。

## 阅读建议

- 图谱数据来自 [knowledge-relations.json](https://github.com/VicHxuan/knowledge-tree/blob/main/src/data/knowledge-relations.json)，随内容目录一起维护；
- 系统性学习请配合[学习路径](/knowledge-tree/learning-paths/)，图谱更适合查依赖、找关联；
- 撰写中（🚧 虚线框）的节点暂无内容页面，点击不会跳转。
