## 学习目标

理解学习式无人机轨迹规划的完整接口：图像如何编码、策略输出如何成为动作或轨迹，以及怎样通过仿真和评估判断导航能力。

## 开始之前

需要基本神经网络和 Python 阅读能力，并对无人机的状态、动作、目标与障碍物有直观认识。前半段补齐视觉骨干与 RL 基础，后半段进入规划、评估和系统部署。

## 完成标准

- 能画出观测编码、策略/轨迹输出、环境执行和奖励反馈的数据流，并写清各接口的物理含义。
- 能说明训练目标与评估指标的区别，给出固定场景、随机种子、基线和失败类型的评估安排。
- 能列出迁移到实机时需要检验的感知误差、时延与动力学差异，并把它们对应到验证环节。

## 延伸方向

- 前半段（CNN → RL 基础 → PPO）与[强化学习学习路径](/knowledge-tree/learning-paths/reinforcement-learning/)高度重合，可以并行推进。
- 轨迹表示与控制接口可继续阅读[经典轨迹规划学习路径](/knowledge-tree/learning-paths/classical-trajectory-planning/)。
- 多机交互与场景泛化评估归入[仿真与评估](/knowledge-tree/simulation-evaluation/)板块，相关章节正在撰写。
