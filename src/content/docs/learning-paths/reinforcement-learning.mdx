## 学习目标

沿着「数学语言 → RL 核心公式 → 算法演进 → PPO → 工程实践」完成一次闭环：能够解释策略为何更新、优势如何估计，以及如何从训练指标定位问题。

## 开始之前

需要能阅读基本微积分、概率符号和 Python 代码。数学尚不熟悉时，从前两步补齐；已经掌握的步骤可以直接标记为完成。撰写中的文章显示为无链接步骤，可以先记录学习进度，后续再回访。

## 完成标准

- 能画出一次 PPO 迭代，标明采样策略、缓存数据、固定训练目标和实际更新的参数。
- 能解释 GAE、概率比值、裁剪目标、价值损失与熵项各自解决的问题。
- 能给出一次小规模训练的配置、监控指标和 checkpoint，并说明如何判断训练是否有效。

## 延伸方向

完成主线后可以按兴趣分支：

- **值方法分支**：DQN 家族与 POMDP（见[算法演进](/knowledge-tree/learning-based-planning/rl-algorithms/rl-foundations/rl-algorithm-evolution/)）。
- **连续控制分支**：DDPG → TD3 → [SAC](/knowledge-tree/learning-based-planning/rl-algorithms/model-free-rl/sac/)。
- **网络骨干**：[CNN](/knowledge-tree/learning-based-planning/neural-network-architectures/cnn/)、[RNN/LSTM](/knowledge-tree/learning-based-planning/neural-network-architectures/rnn-lstm/)、[Attention/Transformer](/knowledge-tree/learning-based-planning/neural-network-architectures/attention-transformer/)——用于设计观测编码器。
