## 延伸方向

完成主线后可以按兴趣分支：

- **值方法分支**：DQN 家族与 POMDP（见[算法演进](/knowledge-tree/learning-based-planning/rl-algorithms/algorithm-evolution/)）；
- **连续控制分支**：DDPG → TD3 → [SAC](/knowledge-tree/learning-based-planning/rl-algorithms/sac/)；
- **网络骨干**：[CNN](/knowledge-tree/learning-based-planning/neural-network-architectures/cnn/)、[RNN/LSTM](/knowledge-tree/learning-based-planning/neural-network-architectures/rnn-lstm/)、[Attention/Transformer](/knowledge-tree/learning-based-planning/neural-network-architectures/attention-transformer/)——设计观测编码器时用得上。
