## 学习目标

沿“模型与数据 → 策略梯度 → 短时域 Actor-Critic → 学习动力学控制”理解无人机模型式控制的核心机制，能够标出每组参数的损失、数据来源和梯度路径。

## 开始之前

先掌握 [强化学习基础](/knowledge-tree/learning-based-planning/rl-algorithms/rl-foundations/reinforcement-learning-foundations/) 与 [梯度、雅可比和 Hessian](/knowledge-tree/mathematics/calculus-optimization/gradient-jacobian-hessian/)。熟悉 PPO 后，可重点比较模型导数与概率比值目标的区别。

## 完成标准

- 能画出世界模型、Actor 与 Critic 的更新关系，标明固定参数和停止梯度的位置。
- 能从短时域目标推出末端价值对策略的梯度，并解释真正终止与计算截断的区别。
- 能区分模型预测准确性与模型导数准确性，提出无人机闭环验证方案。
- 能比较 MBPO、TD-MPC、SHAC 与 Dreamer 的模型用途和部署计算需求。
