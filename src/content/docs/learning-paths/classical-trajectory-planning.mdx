## 学习目标

串起「轨迹表示 → 轨迹生成与优化 → 跟踪控制 → 飞控执行」：知道每一层输入输出是什么，以及规划得到的轨迹怎样转化为可执行的控制量。

## 开始之前

需要基本线性代数、微积分和 C++ 阅读能力。第一步补齐优化语言；板块入口可以按当前任务选择已发布文章，先建立整体链路，再深入具体规划器。

## 完成标准

- 能说明一段轨迹的表示方式、边界条件与连续性要求，并给出生成或优化问题的变量与约束。
- 能解释期望位置、速度、加速度如何进入跟踪控制，以及姿态/角速率环各自承担的任务。
- 能用一张图串起状态估计、规划、控制和执行接口，定位延迟或跟踪误差发生的环节。

## 延伸方向

- **感知侧**：[卡尔曼滤波](/knowledge-tree/classical-planning-control/perception-slam/kalman-filters/)——跟踪控制的状态估计基础。
- **MINCO 参数化**：[系数映射与隐式梯度](/knowledge-tree/classical-planning-control/trajectory-optimization/minco-parameterization/)，再进入 [GCOPTER](/knowledge-tree/classical-planning-control/trajectory-optimization/gcopter-minco/)。
