- [线性代数与几何](/knowledge-tree/mathematics/linear-algebra-geometry/)：矩阵分解、坐标变换、SO(3)/SE(3) 与四元数
- [微积分与优化](/knowledge-tree/mathematics/calculus-optimization/)：梯度与雅可比、优化理论、约束优化与 KKT、数值优化
- [概率统计](/knowledge-tree/mathematics/probability-statistics/) 🚧：概率与贝叶斯推断、高斯与状态估计
- [动力学](/knowledge-tree/mathematics/dynamics/) 🚧：刚体动力学、四旋翼动力学
- [最优控制基础](/knowledge-tree/mathematics/optimal-control-foundations/) 🚧：最优控制建模、Hamilton 与 Pontryagin
