## 板块定位

概率模型描述观测与状态的不确定性，贝叶斯更新融合证据，高斯模型提供可计算的条件推断。

## 阅读主线

概率与条件分布 → 贝叶斯推断 → 高斯条件分布与信息融合 → 感知板块的递归滤波。高斯估计处理静态推断，卡尔曼滤波加入时间传播。
