## 关于本站

本站由 Markdown 原件驱动：知识笔记维护在仓库的 `tech_stack/` 目录，
[同步脚本](https://github.com/VicHxuan/knowledge-tree/blob/main/scripts/sync-docs.mjs)
按 `src/data/content-map.json` 确定性生成 Starlight 页面——正文只改一处，网站自动跟进。
每个页面右上角的编辑链接会直接跳转到对应原件。

发现错误或想补充内容，欢迎在 [GitHub 仓库](https://github.com/VicHxuan/knowledge-tree)提交 Issue 或 Pull Request。
代码采用 MIT 许可，文档内容采用 CC BY 4.0 许可。
