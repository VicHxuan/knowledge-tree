## 板块定位

状态估计恢复机器人运动，环境表示提供碰撞与距离查询，动态跟踪预测障碍物的未来状态。

## 阅读主线

贝叶斯滤波 → 激光或视觉惯性里程计 → 占据网格与距离场 → 动态障碍物跟踪。先统一时间和坐标，再建立估计、地图与规划的接口。
