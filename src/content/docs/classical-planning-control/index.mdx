## 板块定位

经典规划控制将传感器信息转化为状态与地图，搜索运动路径，优化时间轨迹，再通过反馈控制执行。

## 阅读主线

状态估计与建图 → 路径搜索 → 轨迹表示与优化 → 跟踪控制。沿各模块输入输出核对坐标、时间、边界状态和约束。
