## 板块定位

轨迹优化将路径与边界状态变为带时间的连续运动。参数化定义曲线，目标与约束决定优化问题，规划器将这些机制接入在线执行。

## 阅读主线

轨迹表示 → 微分平坦性与最小 Snap → Bézier 与 B 样条 → 安全走廊与优化建模 → MINCO 参数化 → Fast-Planner、EGO-Planner、GCOPTER → 重规划连续性。MINCO 的系数映射和梯度集中在参数化专文。
