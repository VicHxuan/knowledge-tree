## 板块定位

路径搜索在离散图或采样空间中寻找可行连接。启发式、增量修复与动力学扩展分别处理搜索效率、环境变化和运动可达性。

## 阅读主线

图搜索与 A* → 采样规划；地图变化时学习增量搜索，状态包含速度等运动量时学习动力学约束搜索。所有方法都明确边代价与整段碰撞检查。
