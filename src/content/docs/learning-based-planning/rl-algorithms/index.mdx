## 板块定位

决策推理的核心算法库，按「基础 → 无模型 → 有模型」双主线组织：先在强化学习基础中统一数学语言与范式坐标，再沿两条主线深入各自的算法家族。

## 阅读主线

先用强化学习基础统一 MDP、价值函数与策略梯度语言，再按是否使用环境模型分为 Model-Free 与 Model-Based 两条分支。首次学习策略优化可直接沿基础 → PPO → 工程走读推进，TRPO 用于补充信赖域背景。

模型式控制沿 [模型基础 → 可微策略梯度 → SHAC → SuperMimic](/knowledge-tree/learning-paths/model-based-control/) 学习。数据复用与在线规划分别参照 Dyna → MBPO、PETS → TD-MPC。
