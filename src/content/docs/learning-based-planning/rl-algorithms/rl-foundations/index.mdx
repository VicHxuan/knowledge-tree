## 板块定位

建立强化学习的数学定义与方法分类，并讨论部分可观测性和多价值估计两类通用扩展。

## 阅读主线

先读核心公式手册建立数学语言，再用算法演进和模型分类定位各方法。学习 PPO 后，可分别进入 POMDP 与循环策略、多价值网络与价值估计，分析历史信息和多个价值信号对损失及梯度的影响。
