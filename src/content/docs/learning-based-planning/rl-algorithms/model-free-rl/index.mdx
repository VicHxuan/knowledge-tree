## 板块定位

不依赖环境转移模型、直接从交互样本学习策略与值函数的算法主线，分值方法与策略梯度两支；每篇算法页标注其策略数据类型（On/Off-Policy）。

## 阅读主线

两条主线：**值方法：Q-learning → DQN**；**策略优化：PG/Actor-Critic/GAE → PPO**。TRPO 解释信赖域背景；连续控制的 off-policy 分支为 DDPG → TD3 与 SAC。阅读时对齐数据来源、价值目标和策略更新方式。
