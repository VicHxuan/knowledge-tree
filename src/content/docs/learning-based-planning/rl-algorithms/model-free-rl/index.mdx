## 板块定位

直接从交互样本学习策略与价值函数，按网络结构、损失、训练信号与更新流程展开各算法。

## 阅读主线

以强化学习基础中的价值函数和策略梯度为起点：值方法进入 DQN，随机策略优化进入 TRPO 与 PPO，连续动作的离策略方法进入 DDPG、TD3 与 SAC。掌握 PPO 的单 Critic 闭环后，可继续阅读[多价值网络与价值估计](/knowledge-tree/learning-based-planning/rl-algorithms/rl-foundations/multi-critic/)。
