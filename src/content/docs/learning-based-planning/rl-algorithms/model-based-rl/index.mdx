## 板块定位

## 阅读主线

先理解转移模型及其误差，再按模型用途阅读：Dyna/MBPO 生成经验，PETS/MuZero 消费模型进行规划，Dreamer 在想象轨迹中训练策略，最后研究可微模型中的梯度传播。
