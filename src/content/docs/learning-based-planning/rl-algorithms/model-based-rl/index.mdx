## 板块定位

以模型在决策中的用途组织基于模型的强化学习。先明确状态表示和模型来源，再追踪模型如何影响目标、训练数据与策略梯度。无人机主线侧重连续控制、短时域规划和可微动力学。

## 阅读主线

从 [Model-Based RL 基础](/knowledge-tree/learning-based-planning/rl-algorithms/model-based-rl/model-based-rl-foundations/) 开始，按需求选择路线：

| 路线 | 阅读顺序 | 核心问题 |
|---|---|---|
| 模型生成经验 | [Dyna](/knowledge-tree/learning-based-planning/rl-algorithms/model-based-rl/dyna/) → [MBPO](/knowledge-tree/learning-based-planning/rl-algorithms/model-based-rl/mbpo/) | 模型样本如何进入价值与策略损失 |
| 在线规划 | [PETS](/knowledge-tree/learning-based-planning/rl-algorithms/model-based-rl/pets/) → [TD-MPC](/knowledge-tree/learning-based-planning/rl-algorithms/model-based-rl/td-mpc/) | 动作序列如何由预测回报和末端价值评价 |
| 模型内策略学习 | [可微模型与策略梯度](/knowledge-tree/learning-based-planning/rl-algorithms/model-based-rl/differentiable-policy-optimization/) → [SHAC](/knowledge-tree/learning-based-planning/rl-algorithms/model-based-rl/shac/) → [SuperMimic](/knowledge-tree/learning-based-planning/rl-algorithms/model-based-rl/supermimic/) | 动力学和价值导数如何更新 Actor |
