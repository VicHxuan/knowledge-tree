## 板块定位

神经网络架构定义输入信息的组合方式和参数共享关系，任务损失决定表示如何通过梯度更新。

## 阅读主线

MLP 建立结构与反向传播 → CNN 处理空间结构 → RNN 与 LSTM 处理历史 → 编码器与解码器组织共享表示 → Transformer 建立内容相关聚合 → 多尺度与多模态融合。比较输入、目标、梯度路径与部署时可用信息。
