## 板块定位

sensor → 特征提取 → RL 推理 → control 的学习式管线。

## 阅读主线

沿 **观测 → 特征提取 → 策略或规划网络 → 动作/轨迹 → 环境反馈** 阅读。神经网络架构提供表示，RL 提供训练目标，工程实践连接采样和优化，轨迹规划板块解释如何落到无人机任务。
