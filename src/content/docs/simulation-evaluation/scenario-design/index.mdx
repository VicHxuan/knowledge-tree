## 板块定位

训练场景的设计：障碍物密度与课程序列、动态交互行为，以及 sim-to-real 关键的域随机化。

## 阅读主线

先定义静态场景难度与动态交互，再设计课程序列；最后用域随机化控制外观和物理参数的变化范围。训练集与评估集的划分应记录清楚。
