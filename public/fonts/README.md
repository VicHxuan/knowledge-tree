# Heading fonts

Self-hosted Noto Serif SC 600 and Source Serif 4 600, obtained from the Google Fonts CSS API on 2026-11-18. Both use the SIL Open Font License; see the accompanying OFL files.

The Chinese font is a subset of the current technical article H1–H3 text and navigation labels. Its CSS unicode-range declares the included glyphs; future glyphs fall back to the local CJK serif stack. The Latin font uses the standard Latin subset. No external font requests occur while reading.
